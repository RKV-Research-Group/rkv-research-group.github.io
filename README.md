# rkv-research-group.github.io

Professional website of Dr Rajendra Kumar Varma, Associate Professor, Department of Civil Engineering, IIT Jammu.
Live at https://rkv-research-group.github.io

All files sit at the top level of this repository (no folders).

## Where things are

| To change… | Edit this file |
|---|---|
| Menu, footer, email, office | `site.js` (top of file) |
| Publications and conferences | `data.js` — copy a line and edit it |
| Home page text and news | `index.html` |
| Biography, career, industry projects, roles | `about.html` |
| Research themes | `research.html` |
| Projects | `projects.html` |
| Consultancy | `consultancy.html` |
| Students | `group.html` |
| Courses | `teaching.html` |
| Contact | `contact.html` |
| Colours and fonts | `style.css` (`:root` at the top) |

## Adding photos (no code needed)

Upload an image with exactly this name (lowercase, `.jpg`) and it appears automatically:

- `varma.jpg` — portrait on the home page
- `research-frc.jpg`, `research-frp.jpg`, `research-meta.jpg`, `research-waves.jpg`, `research-wind.jpg`, `research-pave.jpg` — research themes (landscape, about 1200 × 900)
- `people-saalim.jpg`, `people-ashfaq.jpg`, `people-swati.jpg`, `people-bhargav.jpg`, `people-haseeb.jpg`, `people-satyendra.jpg` — group members (square)
