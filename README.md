# rkv-research-group.github.io

Professional website of Dr Rajendra Kumar Varma, Associate Professor, Department of Civil Engineering, IIT Jammu.
Live at https://rkv-research-group.github.io

## Where things are

| To change… | Edit this file |
|---|---|
| Menu, footer, email, office | `assets/site.js` (top of file) |
| Publications and conferences | `assets/data.js` — copy a line and edit it |
| Home page text and news | `index.html` |
| Biography, career, roles | `about.html` |
| Research themes | `research.html` |
| Projects | `projects.html` |
| Consultancy | `consultancy.html` |
| Students | `group.html` |
| Courses | `teaching.html` |
| Contact | `contact.html` |
| Colours and fonts | `assets/style.css` (`:root` at the top) |

## Adding photos (no code needed)

Upload an image with exactly this name and it appears automatically:

- `images/varma.jpg` — portrait on the home page
- `images/research-frc.jpg`, `research-frp.jpg`, `research-meta.jpg`, `research-waves.jpg`, `research-wind.jpg`, `research-pave.jpg` — research themes (landscape, about 1200 × 900)
- `images/people/saalim.jpg`, `ashfaq.jpg`, `swati.jpg`, `bhargav.jpg`, `haseeb.jpg`, `satyendra.jpg` — group members (square)

File names are case-sensitive: use lowercase `.jpg`.
